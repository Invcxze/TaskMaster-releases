# TaskMaster — Releases

This repository hosts only the built desktop/mobile binaries and update
manifests for [TaskMaster](https://github.com/Invcxze/TaskMaster).

There is no source code here — see the main repository for that.

## Downloads

Grab the latest installer from the [Releases page](../../releases/latest):

- **macOS** — `.dmg`
- **Windows** — `.msi` or `.exe`
- **Android** — `.apk`

The desktop app also checks this repository automatically and offers
in-app updates.
